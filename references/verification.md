# 简历事实与指标核验

## 必查项目

| 检查对象 | 核验问题 | 缺证据时的处理 |
| --- | --- | --- |
| 本人职责 | 参与、负责、主导与协作范围是否一致 | 保留可证实的职责动词 |
| 项目来源 | 科研、校企、基金子课题能否对应材料 | 不补项目级别 |
| 技术版本 | 不同版本的模型、工具或平台是否真有迭代 | 列冲突，不自动选“新”的名称 |
| 时间 | 入离职、项目、毕业日期能否解释，是否存在并行 | 不将重叠直接判为错误，必要时确认投入方式 |
| 论文 | 作者次序、投稿/返修/录用/发表状态是否准确 | 不把状态提升当润色 |
| 专利 | 申请、受理、实审、授权是否区分 | 按确切状态写 |
| 比例指标 | 指标定义、数据范围、基线和终值是否一致 | 不更换指标名称 |
| 推理速度 | 硬件、输入尺寸、batch和计时范围是否可比 | 限定比较条件，不补FPS |
| 商业成果 | 个人参与与团队签约或量产之间有何证据 | 不把团队结果全部归因本人 |
| 公开发布 | 是否包含原始简历或可识别个人信息 | 仅保留脱敏规律与通用示例 |

## 数字表达

1. 耗时由10分钟降到4.2分钟：耗时下降58%；相同条件下理论吞吐约为原来的2.38倍，不能把两种变化都写成“效率提升58%”。推荐直接写起止耗时和耗时下降比例。
2. 准确率从80%到88%：提高8个百分点，或相对提高10%。不要混用。
3. 从低基准到高终值计算相对提升：`(终值-基准)/基准`；降幅用`(基准-终值)/基准`。基准为0时不计算相对变化。
4. PSNR使用dB差值；SSIM的0—1与百分制表达可以等价换算，但应保持全篇一致，禁止改变指标含义。
5. 检出率、召回率、准确率、mIoU、Dice、mAP各有不同定义；“检测精度”不够明确时列为待确认。
6. 推理耗时下降不单独证明精度不变、满足临床实时或可量产；每个附加结论都需要证据。

## 脱敏示例

以下为教学句式，不代表任何求职者的经历。重写时只使用当前用户提供的事实。

- 原句：参与图像算法优化，效果很好。
- 已确认动作：实现重叠区域加权融合；已确认交付：完成后处理模块；无可信效果数字。
- 改写：针对分块推理的拼接接缝，实现重叠区域加权融合并完成后处理模块开发。
- 禁止补写：误差下降8%、已临床上线、本人主导跨部门落地。

- 原句：负责工艺优化。
- 已确认动作：采用正交试验筛选分散剂和温湿度组合；已确认结果：形成参数建议，尚未量产验证。
- 改写：针对浆料分散稳定性问题，采用正交试验筛选分散剂与温湿度组合，形成工艺参数建议。
- 禁止补写：已实现稳定量产、良率提升12%、带来百万订单。
